Stray dog detection · code walkthrough

What every part of the code does

Every pipeline file is shown in small groups of lines, each followed by a plain-English explanation. Grey numbers are line numbers, so you can find the same spot in the repository.

Order the files run in

  1. scripts/download_data.sh: download and unzip the footage
  2. train_clock_reader.py, then prepare.py: real recording times, duplicates, the manifest
  3. detect.py: YOLO on 3 frames per second (uses video.py)
  4. track.py, then stats.py: tracks, visits, activity, charts
  5. select_eval_frames.py → you label with label_tool.html → import_labels.py → evaluate.py: accuracy
  6. tune_tracker.py: tracker settings for the final detector, on dev clips
  7. examples.py and reid_demo.py: gallery and recognition demo

scripts/run_all.sh runs all of this in order with one command.

config.py (settings), clock_ocr.py (the clock reader) and boxes.py (box tools) are used by the others.

2src/video.py

The frame sampler. Every step that needs video frames (detection, choosing evaluation frames) uses this one function, so frame number i always means exactly the same picture everywhere.

1"""Frame sampling: decode a clip at a fixed rate and downscale, via an ffmpeg pipe.
2 
3HEVC 2560x1440 is expensive to decode; ffmpeg's fps filter drops frames before
4scaling so only the kept frames are converted. Frame i has timestamp i / fps.
5"""

Docstring: decoding H.265 video at 2560x1440 is slow, so the program ffmpeg drops unwanted frames first and only shrinks the ones that are kept.

6import subprocess
7import numpy as np

subprocess runs another program (ffmpeg) from Python. numpy handles arrays of numbers, which is how images are stored.

10def iter_frames(path, fps=3, width=1280, height=720):

Defines the function iter_frames. It is a generator: instead of returning all frames at once (which would fill the memory), it hands them back one by one as the caller asks for them.

11    cmd = ["ffmpeg", "-v", "quiet", "-i", str(path), "-an",
12           "-vf", f"fps={fps},scale={width}:{height}:flags=area",
13           "-f", "rawvideo", "-pix_fmt", "bgr24", "-"]

Builds the ffmpeg command. -v quiet: no log messages. -i: the input video. -an: ignore the audio. -vf: video filters, first fps=3 (keep 3 frames per second), then scale to 1280x720 using the 'area' method, which gives clean downscaling. rawvideo + bgr24: output plain pixel values, 3 bytes per pixel in Blue-Green-Red order (the order OpenCV expects). -: send the output to Python instead of a file.

14    p = subprocess.Popen(cmd, stdout=subprocess.PIPE, bufsize=10 ** 8)

Starts ffmpeg and connects its output to a pipe Python can read from, with a large buffer for speed.

15    n = width * height * 3
16    i = 0

n = the number of bytes in one frame (width x height x 3 colours). i counts frames from 0.

17    try:
18        while True:
19            buf = p.stdout.read(n)
20            if len(buf) < n:
21                break
22            yield i, i / fps, np.frombuffer(buf, np.uint8).reshape(height, width, 3)
23            i += 1

Loop: read exactly one frame's worth of bytes. If fewer bytes come back, the video has ended, so stop. Otherwise yield three things: the frame number, its time in seconds (i / fps, so frame 6 at 3 fps is 2.0 s) and the picture, reshaped from a flat list of bytes into a height x width x 3 image. Then move to the next frame number.

24    finally:
25        p.stdout.close()
26        p.wait()

finally always runs, even if the caller stops early: close the pipe and wait for ffmpeg to exit, so no stray processes are left behind.

4src/clock_ocr.py

Reads the date and time burned into the top-left of every frame. This was needed because Camera1's filenames are export times, not recording times. General text recognition (Tesseract) failed on bright backgrounds, so this file recognises each digit separately by its shape.

1"""Read the burned-in camera clock (e.g. '2025/01/07 06:22:29', top-left of frame).
2 
3Why not plain Tesseract: the overlay is white text with a thin dark outline. On
4bright daytime backgrounds the fill blends into the sky and Tesseract fails
5(2/20 clips read in a test). The font, size and position are fixed, so instead each
6of the 14 digit cells is cut out at a known position and classified by a small
7k-NN on HOG features.
8 
9Training labels come for free: Camera3/Camera4 filenames are Unix-ms start times,
10so the clock value of every frame in those clips is known (start + t + offset).
11The trained reader is checked on held-out clips and then used for Camera1, whose
12filenames are export times, not recording times.
13"""

Docstring explaining the reason for this approach, as above.

14import datetime as dt
15import subprocess
16import numpy as np
17import cv2
18from skimage.feature import hog

Imports: datetime for dates and times, subprocess for ffmpeg, numpy for arrays, cv2 (OpenCV) for image processing, and hog from scikit-image, a standard way to describe the shape of a small image.

20FULL_W, FULL_H = 2560, 1440

The original video size, 2560x1440.

21CROP = (120, 40, 940, 120)            # x0, y0, x1, y1 in full-res pixels

The rectangle (left, top, right, bottom) that contains the clock text, in original-size pixels.

22# on-screen clock = floor(filename_start + t + CLOCK_LEAD) (measured on Cam3 night clips)
23CLOCK_LEAD = 0.9

Measured fact: the on-screen clock runs 0.9 seconds ahead of the time in Camera3/4 filenames.

24PITCH, X0, CELL_W, Y0, Y1 = 42, 128, 40, 48, 110

The clock's fixed layout: characters are 42 pixels apart (PITCH), the first starts at x = 128, each digit is cut out 40 pixels wide, and the text spans y = 48 to 110.

25DIGIT_POS = [0, 1, 2, 3, 5, 6, 8, 9, 11, 12, 14, 15, 17, 18]   # YYYY MM DD HH MM SS

Which of the 19 character positions in 2025/01/07 06:22:29 are digits: everything except the two slashes (positions 4 and 7), the space (10) and the two colons (13 and 16). That leaves 14 digits: YYYY MM DD HH MM SS.

28def read_clock_strip(path, every_n=15, fps=15, phase=0):
29    """Decode only the clock strip of every n-th frame. Returns (times_s, gray_strips)."""

Function that decodes only the clock area, from every n-th frame of a clip.

30    x0, y0, x1, y1 = CROP
31    w, h = x1 - x0, y1 - y0

Unpacks the rectangle and works out its width and height.

32    cmd = ["ffmpeg", "-v", "quiet", "-i", str(path), "-an",
33           "-vf", f"select='eq(mod(n\\,{every_n})\\,{phase})',crop={w}:{h}:{x0}:{y0},format=gray",
34           "-fps_mode", "passthrough", "-f", "rawvideo", "-"]

ffmpeg command. select=... keeps only frames whose number divided by every_n leaves remainder phase (with 15 and 7: frames 7, 22, 37, ...). crop cuts out the clock strip, format=gray makes it black and white, and passthrough keeps the original frame timing.

35    raw = subprocess.run(cmd, capture_output=True).stdout
36    strips = np.frombuffer(raw, np.uint8).reshape(-1, h, w)

Runs ffmpeg, collects the raw bytes, and reshapes them into a stack of clock-strip images.

37    times = (np.arange(len(strips)) * every_n + phase) / fps
38    return times, strips

Works out each strip's time in seconds: (strip number x every_n + phase) / 15 fps. Returns the times and the strips.

41def cells(strip):
42    """Cut the 14 digit cells out of one clock strip -> (14, feat) HOG features."""

Function that cuts the 14 digits out of one clock strip and describes each one's shape.

43    out = []
44    for k in DIGIT_POS:
45        xa = X0 + PITCH * k - CROP[0]
46        c = strip[Y0 - CROP[1]:Y1 - CROP[1], xa:xa + CELL_W]

For each digit position: its left edge inside the strip (xa), then slices that cell out, from y = 48 to 110.

47        c = cv2.resize(c, (32, 48), interpolation=cv2.INTER_AREA)
48        c = cv2.equalizeHist(c)

Resizes every cell to the same 32x48 size, then equalises its brightness: stretches the contrast so a digit on bright sky and a digit at night end up looking alike.

49        out.append(hog(c, orientations=9, pixels_per_cell=(8, 8), cells_per_block=(2, 2)))
50    return np.stack(out)

HOG (Histogram of Oriented Gradients) describes the cell by the direction of its edges in small 8x8 patches, which captures the digit's shape and ignores colour and brightness. The 14 descriptions are stacked and returned.

53def digits_of(t: dt.datetime):
54    return [int(ch) for ch in t.strftime("%Y%m%d%H%M%S")]

Turns a date-time into its 14 digits. For example, 2025-01-07 06:22:29 becomes [2,0,2,5,0,1,0,7,0,6,2,2,2,9]. Used to make training labels.

57class ClockReader:
58    def __init__(self, k=3):
59        self.k = k
60        self.X = self.y = None

The digit reader, a k-nearest-neighbours classifier: to recognise a digit, find the k = 3 most similar digits it has seen before and let them vote. X stores the example shapes and y their correct digits.

62    def fit(self, X, y):
63        self.X = X.astype(np.float32)
64        self.X /= np.linalg.norm(self.X, axis=1, keepdims=True) + 1e-6
65        self.y = np.asarray(y)
66        return self

fit ('training'): for k-NN this just stores the examples. Each is scaled to length 1 so that comparing two of them measures shape similarity only.

68    def predict_digits(self, F):
69        F = F.astype(np.float32)
70        F /= np.linalg.norm(F, axis=1, keepdims=True) + 1e-6
71        sim = F @ self.X.T
72        idx = np.argsort(-sim, axis=1)[:, :self.k]
73        votes = self.y[idx]
74        return np.array([np.bincount(v, minlength=10).argmax() for v in votes])

predict_digits: scale the new cells the same way, compute their similarity to every stored example in one matrix multiplication (@), take the 3 most similar (argsort), and return the digit that wins the vote (bincount(...).argmax()).

76    def read(self, strip):
77        d = "".join(map(str, self.predict_digits(cells(strip))))
78        try:
79            return dt.datetime.strptime(d, "%Y%m%d%H%M%S")
80        except ValueError:
81            return None

read: predicts the 14 digits, joins them into text like 20250107062229 and turns that into a date-time. If the result is impossible (for example month 13), it returns None instead of crashing.

83    def clip_start(self, path):
84        """Robust clip start: median over all sampled frames of (reading - t)."""
85        times, strips = read_clock_strip(path, phase=7)
86        starts = []
87        for t, s in zip(times, strips):
88            r = self.read(s)
89            if r is not None:
90                starts.append(r.timestamp() - t)
91        if not starts:
92            return None, 0, len(times)

clip_start: reads the clock in every 15th frame of a clip (frames 7, 22, 37, ..., i.e. half-way through each second). For each successful reading it subtracts that frame's time to get the implied clip start. If nothing could be read, it returns nothing.

93        # clock shows floor(true + lead); +0.5 recentres the 1 s quantisation, -lead removes the lead
94        med = float(np.median(starts)) + 0.5 - CLOCK_LEAD
95        agree = sum(abs(s - med) <= 2 for s in starts)
96        return dt.datetime.fromtimestamp(med), agree, len(times)

Takes the median of all implied start times, so an occasional misread frame doesn't matter. Adds 0.5 s, because a clock showing whole seconds is on average half a second behind, and subtracts the 0.9 s lead. Also counts how many frames agree within 2 seconds, as a confidence check. Returns the start time, the agreeing count and the frame count.

98    def save(self, p):
99        np.savez_compressed(p, X=self.X, y=self.y, k=self.k)
100 
101    @classmethod
102    def load(cls, p):
103        z = np.load(p)
104        r = cls(int(z["k"]))
105        r.X, r.y = z["X"], z["y"]
106        return r

save / load: store the trained reader in a compressed .npz file and read it back.

26def md5(path):
27    h = hashlib.md5()
28    with open(path, "rb") as f:
29        for b in iter(lambda: f.read(1 << 20), b""):
30            h.update(b)
31    return h.hexdigest()

88def ap_and_curve(scores, tps, n_gt):
89    o = np.argsort(-scores)
90    s, t = scores[o], tps[o]
91    tp, fp = np.cumsum(t), np.cumsum(~t)
92    rec = tp / max(n_gt, 1)
93    prec = tp / np.maximum(tp + fp, 1)
94    mpre = np.concatenate([[0], prec, [0]])
95    mrec = np.concatenate([[0], rec, [rec[-1] if len(rec) else 0]])
96    for i in range(len(mpre) - 2, -1, -1):
97        mpre[i] = max(mpre[i], mpre[i + 1])
98    idx = np.where(mrec[1:] != mrec[:-1])[0]
99    ap = float(np.sum((mrec[idx + 1] - mrec[idx]) * mpre[idx + 1]))
100    return ap, s, prec, rec

ap_and_curve: sorts boxes by confidence and walks down the list. At each step, recall = dogs found so far / all dogs and precision = correct boxes so far / boxes so far. The precision line is smoothed so it never goes up again (the standard rule), and the area under the precision-recall curve is the AP.

103def at_threshold(scores, tps, n_gt, thr):
104    k = scores >= thr
105    tp, fp = int(tps[k].sum()), int((~tps[k]).sum())

7def iou(a, B):
8    """Intersection-over-union of box a with every box in B (N x 4)."""
9    B = np.asarray(B).reshape(-1, 4)
10    if len(B) == 0:
11        return np.zeros(0)
12    ix = np.clip(np.minimum(a[2], B[:, 2]) - np.maximum(a[0], B[:, 0]), 0, None)
13    iy = np.clip(np.minimum(a[3], B[:, 3]) - np.maximum(a[1], B[:, 1]), 0, None)
14    inter = ix * iy
15    ua = (a[2] - a[0]) * (a[3] - a[1]) + (B[:, 2] - B[:, 0]) * (B[:, 3] - B[:, 1]) - inter
16    return inter / np.maximum(ua, 1e-9)

iou: Intersection over Union of box a with every box in B: the overlapping area (0 if they don't touch) divided by the area the two boxes cover together. 1 = identical, 0 = no overlap.

60def cluster(E, cannot):
61    """Average-linkage agglomerative clustering on cosine distance with cannot-link pairs."""
62    groups = [[i] for i in range(len(E))]
63    S = E @ E.T
64    while True:
65        best, pair = 1 - LINK_DIST, None
66        for a in range(len(groups)):

68                if any((i, j) in cannot for i in groups[a] for j in groups[b]):

18tools/label_tool.html

The labelling page you used. It is a web page (HTML, CSS and JavaScript), not part of the Python pipeline, so it is explained block by block rather than line by line.

Top of the file. The page title, fonts from Google Fonts, and the style rules (CSS). Colours are defined once as tokens such as --accent and --box, with a second set for dark mode.

Page layout (HTML). The progress bar and counter; the chips showing camera, day/night and status; the 'How to label' guide; the image area (#canvas) holding the image, your saved boxes (#boxes) and the box being drawn (#ghostLayer); the list of boxes with delete buttons; the status line; and the toolbar buttons.

State variables. frames: the 180 frames. idx: which one is shown. labels: everything saved so far. cur: the boxes of the current frame. sel: the selected box. Plus zoom, pan mode and the connection to the database.

Local drafts. Unsaved changes are also kept in the browser's own storage (localStorage), so a dropped connection doesn't lose a box. The last frame you were on is remembered too.

load(i). Shows frame number i: saves the previous frame first, picks up its saved boxes (or a draft), sets the image, and updates the chips and buttons.

render(). Redraws the boxes, labels and the box list from cur. Box positions are stored as fractions of the image (0 to 1), so they line up at any zoom or screen size.

touched() and flush(). After any change, touched() waits 1.2 s for more changes, then flush() saves the frame to the database as labels/<frame id> with its boxes, status (done or skip) and the time. This is the data the evaluation reads.

Drawing. Finger down starts a box at that point; moving stretches the blue outline; finger up creates the box. A movement under 14 px counts as a tap, which selects the smallest box under your finger. A second finger is ignored while drawing.

Buttons and keys. Prev, Next, Next unlabelled, Hard, Delete, Zoom (1x, 2x, 3x), Draw/Pan, Skip, No dogs and Done. On a keyboard: N, P, Backspace, H, 0, Enter and Z.

Loading data. Fetches the frame list (frames.json), then subscribes to the database so saved labels appear immediately and stay up to date. If the database can't be reached, a message says so.
